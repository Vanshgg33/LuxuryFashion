# 🍽️ Rangeela Dhaba – Restaurant Management & Online Ordering System

A full-stack restaurant management and online ordering platform built to streamline customer ordering and backend operations for a real-world restaurant.

🔗 **Live Demo:** https://www.rangeeladhaba.in/

---

## 🚀 Overview

This system allows customers to browse the menu and place orders seamlessly, while providing administrators with powerful tools to manage products, orders, promotions, and analytics.

The backend is designed using a modular architecture with scalable APIs, secure authentication, and efficient data handling.

---

## ✨ Features

### 👤 Customer Features
- Browse menu and place orders
- Smooth and responsive ordering experience
- Real-time interaction with backend services

### 🛠️ Admin Panel
- Add, update, and manage products
- Configure coupons and offers
- Customize banners and promotions
- View and manage all incoming orders
- Monitor business performance via analytics

### 🍳 Kitchen System (KOT)
- Kitchen Order Ticket (KOT) system
- Real-time order flow to kitchen
- Streamlined order processing workflow

### 🔐 Authentication & Authorization
- JWT-based authentication
- Role-Based Access Control (RBAC)
- Secure API endpoints for admin and staff

## 📦 Core Modules

- **Order Management System**  
  Handles order creation, updates, and tracking.

- **Product & Inventory Management**  
  Dynamic product handling for admin users.

- **Coupon & Banner System**  
  Marketing tools for promotions and offers.

- **Analytics Dashboard**  
  Tracks orders, user activity, and performance.

- **KOT System**  
  Optimized kitchen workflow and order visibility.

---

## 📌 Architecture

The backend follows a modular structure:
- **Controllers** → Handle API requests  
- **Services** → Business logic  
- **Modules** → Feature-based organization  
- **Database** → MongoDB collections for users, orders, products
